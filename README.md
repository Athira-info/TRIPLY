# TRIPLY

TRIPLY is a travel planning web application designed to help users explore destinations, discover places, save favourites, and organize their trips in one place.

## Features

- Explore travel destinations
- View destination details
- Create and manage trips
- Save favourite places
- User profile
- Interactive navigation
- Responsive web interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Live Demo

[View TRIPLY Live Demo](https://athira-info.github.io/TRIPLY/)

## Project Purpose

TRIPLY was developed as a front-end web project focusing on user experience, interface design, navigation, and interactive travel planning features.
